## 🔬 2. Теоретичні відомості та математична модель

### 2.1. Типи ознак у системі
1. **Кількісні ознаки ($x_{\text{quant}}$):**
   Числові неперервні або дискретні величини (ціна, ємність акумулятора, пам'ять тощо). Через різний масштаб вони приводяться до безрозмірного діапазону $[0, 1]$ за допомогою **Min-Max нормалізації**:
   $$z_{i} = \frac{x_i - x_{\min}}{x_{\max} - x_{\min}}$$
   Різниця між двома об'єктами:
   $$d(x_i^{(A)}, x_i^{(B)}) = |z_i^{(A)} - z_i^{(B)}|$$

2. **Якісні порядкові (рангові) ознаки ($x_{\text{ord}}$):**
   Властивості, які можна впорядкувати за ступенем прояву (наприклад: *Немає* $\to$ *IP54* $\to$ *IP68*).
   Нормуються на інтервал $[0, 1]$ за рангом:
   $$z_{\text{ord}} = \frac{\text{rank} - 1}{N_{\text{levels}} - 1}$$
   Різниця:
   $$d(q_i^{(A)}, q_i^{(B)}) = |z_{\text{ord}}^{(A)} - z_{\text{ord}}^{(B)}|$$

3. **Якісні бінарні ознаки ($x_{\text{bin}}$):**
   Наявність або відсутність ознаки (*Так / 1* або *Ні / 0*):
   $$d(b_i^{(A)}, b_i^{(B)}) = |b_i^{(A)} - b_i^{(B)}| \in \{0, 1\}$$

4. **Якісні номінальні (категоріальні) ознаки ($x_{\text{nom}}$):**
   Властивості без природного порядку (наприклад: *Пластик, Скло, Алюміній, Титан*). Відстань між ними визначається мірою співпадіння:
   $$d(q_i^{(A)}, q_i^{(B)}) = \begin{cases} 0, & \text{якщо значення збігаються} \\ 1, & \text{якщо значення різні} \end{cases}$$

---

### 2.2. Узагальнена зважена міра Евкліда
Відстань між об'єктом $X$ та еталоном/об'єктом $Y$ обчислюється як:
$$D(X, Y) = \sqrt{\frac{\sum_{i=1}^{n} w_i \cdot d_i(x_i, y_i)^2}{\sum_{i=1}^{n} w_i}}$$
де:
- $w_i$ — ваговий коефіцієнт важливості $i$-ї ознаки;
- $d_i(x_i, y_i) \in [0, 1]$ — нормована різниця значень $i$-ї ознаки.

### 2.3. Алгоритми прийняття рішень
1. **Метод мінімальної відстані до еталону (Nearest Centroid):**
   Для кожного класу обчислюється центр (еталонний вектор) $\bar{C}_k$. Об'єкт відноситься до класу $k^*$, для якого відстань є мінімальною:
   $$k^* = \arg\min_k D(X, \bar{C}_k)$$
2. **Метод $k$-найближчих сусідів ($k$-NN):**
   Знаходяться $k$ найближчих об'єктів навчальної вибірки. Клас визначається зваженим голосуванням з вагами $w_{\text{vote}} = \frac{1}{D(X, Y_j) + \varepsilon}$.

## 🚀 5. Інструкція із запуску

### Варіант А: Запуск графічного інтерфейсу (GUI)
Двічі клацніть файл **`start.bat`** або виконайте у терміналі:
```bash
py gui_app.py
```
*У графічному інтерфейсі доступні повзунки для кількісних параметрів, списки якісних параметрів, кнопки швидкого завантаження пресетів, динамічні шкали відстаней та візуалізація $k$-NN.*

### Варіант Б: Запуск консольного режиму
```bash
py main.py
```
Меню дозволяє:
1. Запустити повне автоматичне тестування на контрольних прикладах.
2. Ввести характеристики власного девайса для класифікації.
3. Переглянути базу знань (еталони класів).
4. Запустити GUI безпосередньо з консолі.
