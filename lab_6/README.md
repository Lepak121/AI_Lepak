# Лабораторна робота №6: Розроблення інтелектуального бота з використанням технологій ШІ

## 🌍 Предметна область: Консультант з туризму та бронювання турів («Wanderlust AI»)

**Wanderlust AI** — це інтелектуальний асистент турагенції, розроблений для автоматизації консультацій клієнтів, інтерактивного підбору подорожей, бронювання путівок, надання кліматичних довідок та перевірки візових вимог.

---

## 📌 1. Сценарії використання (Use Cases)

1. **UC-1: Пошук та персоналізований підбір турів**
   * *Опис:* Користувач звертається із запитом на пошук відпочинку (пляжний, екскурсійний, гірськолижний, спа), вказуючи або уточнюючи країну, бюджет чи тривалість.
   * *Результат:* Бот аналізує базу турів та повертає підібрані варіанти з цінами, готелями та описом.

2. **UC-2: Багатокрокове бронювання поїздки (Multi-turn Slot Filling)**
   * *Опис:* Користувач висловлює намір забронювати тур.
   * *Результат:* Бот підхоплює раніше обраний тур, кількість мандрівників, розраховує фінальну суму та формує попередню заявку на резервацію.

3. **UC-3: Довідка про погоду та сезонність (Weather & Climate Guide)**
   * *Опис:* Користувач цікавиться температурою моря, повітря, сезоном дощів чи оксамитовим періодом у вибраній країні.
   * *Результат:* Бот надає кліматичну довідку щодо оптимального часу для поїздки.

4. **UC-4: Візовий консалтинг та вимоги до документів (Visa & Entry FAQ)**
   * *Опис:* Запит щодо терміну дії закордонного паспорта, правил в'їзду з дітьми, наявності безвізу для громадян України або страхування.
   * *Результат:* Надання чітких інструкцій щодо перетину кордону.

5. **UC-5: Скасування або перенесення туру (Cancellation & Refund)**
   * *Опис:* Користувач запитує про умови відмови від туру, повернення коштів або форс-мажорні ситуації.
   * *Результат:* Роз'яснення політики туроператора та порядку звернення.

6. **UC-6: Ескалація на живого оператора (Human Handoff)**
   * *Опис:* Якщо бот стикається з нетиповим питанням або клієнт вимагає менеджера, відбувається передача діалогу живому консультанту.

## 🎯 2. Список намірів (Intents)

Система розпізнає **8 ключових намірів** (мінімум за вимогами: 5-7):

| № | Назва наміру (Intent) | Опис наміру | Приклади повідомлень користувача |
|---|-----------------------|-------------|----------------------------------|
| 1 | `greeting` | Привітання, початок діалогу | *«Привіт», «Доброго дня!», «Салют, друже!», «Хеллоу, допоможи мені»* |
| 2 | `search_tours` | Пошук турів за напрямками, стилем чи бюджетом | *«Підбери тур в Єгипет», «Шукаю пляжний відпочинок до 1000$», «Хочу в Рим на 7 днів»* |
| 3 | `book_tour` | Бронювання або резервація обраного туру | *«Хочу забронювати цей тур», «Оформи мені бронювання на двох», «Купуємо поїздку»* |
| 4 | `check_weather` | Інформація про погоду, клімат, температуру води | *«Яка зараз погода в Єгипті?», «Чи тепле море в Туреччині у жовтні?», «Коли сезон на Балі?»* |
| 5 | `faq_visa_docs` | Питання щодо віз, паспорта, правил виїзду, страховки | *«Чи потрібна віза в Італію?», «Скільки ще має діяти закордонний паспорт?», «Документи для дітей»* |
| 6 | `cancel_or_change` | Скасування броні, зміна дат, повернення грошей | *«Як скасувати бронювання?», «Чи можна повернути гроші за тур?», «Хочу змінити дату вильоту»* |
| 7 | `human_operator` | Виклик живого менеджера турагенції | *«З'єднай з живим оператором», «Хочу поговорити з менеджером», «Дайте телефон підтримки»* |
| 8 | `goodbye` | Завершення бесіди, слова подяки | *«Дякую, до побачення», «Гарного дня!», «Бувай, на все добре», «Щиро вдячний за допомогу»* |

## 🏷 3. Виділення сутностей (Entities)

Для точного заповнення слотів (slot filling) розпізнаються наступні сутності:

| Сутність (Entity) | Тип значення | Опис | Приклади виділення |
|-------------------|--------------|------|--------------------|
| `destination` | String | Країна або курортне місто (з урахуванням відмінків) | *«в Єгипет» → «Єгипет», «в Анталії» → «Туреччина», «до Риму» → «Італія»* |
| `budget` | Object / Number | Сума або ціновий діапазон з валютою ($ / € / ₴) | *«до 1000 євро» → `{amount: 1000, currency: "EUR"}`*, *«$800» → `{amount: 800, currency: "USD"}`* |
| `travelers_count` | Integer | Кількість подорожуючих | *«на двох» → 2*, *«на одного» → 1*, *«сім'я з дитиною» → 3*, *«4 особи» → 4* |
| `tour_type` | String | Формат відпочинку | *«на море» / «пляж» → «пляжний»*, *«музеї» / «екскурсії» → «екскурсійний»*, *«лижі» → «гірськолижний»* |
| `duration` | String | Тривалість туру | *«на 7 днів» → «7 днів»*, *«на вихідні» → «3-4 дні (вихідні)»*, *«на тиждень» → «7 днів»* |

## ⚙️ 4. Архітектура та тип бота

Обрано **Гібридну архітектуру (Hybrid ML + Slot Filling + Context Memory + LLM Fallback)**:

```
[Повідомлення користувача]
           │
           ▼
┌──────────────────────────────────────────────┐
│        1. NLP Processor & Stemmer            │
│  - Очищення тексту, токенізація              │
│  - Евристичний стемінг української мови      │
└──────────────────────────────────────────────┘
           │
           ├──────────────────────────────────────────┐
           ▼                                          ▼
┌─────────────────────────────┐        ┌──────────────────────────────┐
│  2. ML Intent Classifier    │        │  3. Rule-based Entity        │
│  - TF-IDF Vectorizer (1-2)  │        │     Extractor (NER)          │
│  - Logistic Regression (ML) │        │  - Словник курортів та міст  │
│  - Calibrated Probabilities │        │  - Регулярні вирази валют/осіб│
└─────────────────────────────┘        └──────────────────────────────┘
           │                                          │
           ▼                                          ▼
┌─────────────────────────────────────────────────────────────────────┐
│                 4. Dialogue & Context Manager (Memory)              │
│  - Multi-turn Memory: збереження історії реплік                     │
│  - Slot Filling: накопичення параметрів туру (destination, budget)  │
│  - State Machine: керування сценаріями (search_tours / booking)     │
└─────────────────────────────────────────────────────────────────────┘
           │
     [Confidence < 0.28?]
      ├─── ТАК ───► ┌──────────────────────────────────────────────┐
      │             │  5. LLM Fallback & Prompt Engineering        │
      │             │  - Роль тревел-консультанта 'Wanderlust'     │
      │             │  - Підтримка OpenAI / Groq / Gemini API      │
      │             │  - Автономний евристичний fallback           │
      │             └──────────────────────────────────────────────┘
      │
      └─── НІ ────► [Генерація точної відповіді та фільтрація турів]
```

## 💻 6. Інструкція із запуску

### Встановлення залежностей:
```bash
pip install -r requirements.txt
```

### 1. Запуск оцінки та валідації моделі (ML метрики):
```bash
python evaluate_model.py
```

### 2. Запуск консольного режиму (CLI):
```bash
python cli_bot.py
```
*У CLI доступні команди: `reset` (очистити пам'ять діалогу), `exit` (вийти).*

### 3. Запуск сучасного Веб-інтерфейсу (Web UI):
```bash
python web_app.py
```
Відкрийте браузер за адресою: **[http://localhost:5000](http://localhost:5000)**.
Веб-додаток містить інтерактивний чат, панель **AI Inspector** із відображенням розпізнаного наміру, відсотка впевненості, виявлених сутностей, слотів пам'яті та діаграми розподілу ймовірностей для всіх намірів.
