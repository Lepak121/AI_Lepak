# 👁️ OpenCV Vision Studio (Лабораторна робота №5)
**Дисципліна:** Системи штучного інтелекту  
**Тема:** Робота з бібліотекою комп'ютерного зору OpenCV: детекція, сегментація та розпізнавання об'єктів на Python.

---

## 🌟 Основний функціонал проєкту

Проєкт реалізує повноцінну інтелектуальну систему комп'ютерного зору з двома інтерфейсами (сучасний GUI на Tkinter/Pillow та CLI консоль):

1. **👤 Детекція облич та очей (Face & Eye Detection)**:
   - Класифікація на базі каскадних класифікаторів Хаара (`haarcascade_frontalface_default.xml` та `haarcascade_eye.xml`).
   - Підсвітка рамок облич, виділення очей та відображення кількості знайдених суб'єктів.

2. **📱 Розпізнавання та декодування QR-кодів (QR Code Decoder)**:
   - Автоматична локалізація кутів та меж QR-коду за допомогою `cv2.QRCodeDetector`.
   - Зчитування закодованих посилань та текстових повідомлень у реальному часі.

3. **🔷 Контурний аналіз: розпізнавання геометричних фігур та кольорів (Shapes & Colors)**:
   - Виявлення замкнених контурів (`cv2.findContours`).
   - Апроксимація полігонів методом Рамера-Дугласа-Пекера (`cv2.approxPolyDP`): трикутники, квадрати, прямокутники, п'ятикутники, кола.
   - Визначення домінуючого кольору фігури в колірному просторі HSV (червоний, синій, зелений, оранжевий, жовтий, фіолетовий тощо).

4. **🏃 Детекція руху (Motion Detection & Tracking)**:
   - Покадрове віднімання (Frame Differencing) з гаусовим розмиттям та бінаризацією.
   - Обведення зон активності червоними маркерами та підрахунок площі руху.

5. **⚡ Виділення меж (Canny Edge Detection)**:
   - Знаходження градієнтних контурів з можливістю налаштування порогів чутливості у реальному часі.

## 🚀 Швидкий запуск

### Варіант 1: Запуск в 1 клік (Windows)
- Двічі клікніть на **`start.bat`** — відкриється графічний інтерфейс програми.
- Або двічі клікніть на **`run_console.bat`** — відкриється інтерактивне консольне меню.

### Варіант 2: Запуск через термінал
```powershell
# Запуск графічного інтерфейсу
.venv\Scripts\python main.py

# Запуск інтерактивного консольного меню
.venv\Scripts\python main.py --console

# Автономна обробка конкретного режиму
.venv\Scripts\python main.py --mode face
.venv\Scripts\python main.py --mode qr
.venv\Scripts\python main.py --mode shapes

# Генерація офіційного Word-звіту (.docx)
.venv\Scripts\python main.py --report
```

## 🛠️ Використані бібліотеки та технології
- **Python 3.12**
- **OpenCV (opencv-python)** — основна бібліотека комп'ютерного зору
- **NumPy** — матричні обчислення над пікселями зображень
- **Pillow (PIL)** — робота з растровими зображеннями в GUI
- **qrcode** — генерація валідних QR-кодів
- **python-docx** — автоматична побудова звіту з лабораторної роботи
